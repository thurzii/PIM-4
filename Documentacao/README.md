# Documentação

Relatórios, textos e documentos do grupo — inclusive de outras matérias.

## Como organizar

Crie uma subpasta por matéria ou por entrega, para não virar uma pilha de arquivos soltos:

```
Documentacao/
├── Engenharia-de-Software/
├── Banco-de-Dados/
└── Relatorio-Final/
```

## Nome dos arquivos

Use nomes que digam o que é e de quando é. `Relatorio-Final-2026-10-20.docx` se acha em um segundo; `documento final (2) revisado FINAL.docx` não.

Evite acentos e espaços nos nomes: alguns sistemas tratam mal, e o endereço do arquivo no GitHub fica cheio de códigos estranhos. Use hífen no lugar do espaço.

## Documentos editáveis em grupo

Arquivos do Word e do Excel são binários — o Git não consegue juntar duas versões, então se duas pessoas editarem ao mesmo tempo, uma perde o trabalho.

Para documentos que várias pessoas vão escrever ao mesmo tempo, é melhor usar o Word Online ou o Google Docs e colocar aqui só a versão final, ou o link.

## Limite de tamanho

O GitHub recusa arquivos acima de **100 MB**. PDFs com muitas imagens em alta resolução chegam perto disso — se for o caso, comprima antes ou deixe o arquivo no Drive e coloque o link aqui.
