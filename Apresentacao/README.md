## Vídeos não vão neste repositório

O GitHub recusa qualquer arquivo acima de **100 MB**, e uma gravação de 10 minutos passa disso com folga. Pior: quando um arquivo grande é recusado, o push falha **inteiro** — nenhum dos outros arquivos daquele envio sobe.

Então, para vídeo:

1. Suba no **Teams** ou no **Google Drive**
2. Gere o link de compartilhamento

## Requisitos da apresentação em grupo

Conforme o enunciado do professor:

- Modelagem
- Sistema funcionando
- Desk
- **10 minutos no máximo**

## Dividindo os 10 minutos

Uma divisão que costuma funcionar, com quatro integrantes:

| Bloco | Tempo | Conteúdo |
|---|---|---|
| Abertura e contexto | 1 min | Que sistema é, quais perfis existem |
| Modelagem | 2–3 min | Casos de uso, classes, como o modelo virou código |
| Sistema funcionando | 4–5 min | Login nos dois perfis, CRUD, progresso do aluno |
| Fechamento | 1 min | Conceitos aplicados e resultado |

Deixe o banco com poucos dados antes de apresentar: uma tela cheia de registros de teste atrapalha mais do que ajuda.

## Ensaie com cronômetro

Dez minutos passam muito mais rápido do que parece. Ensaiem pelo menos uma vez inteiro, cronometrando — é a única forma de descobrir qual parte precisa encolher.
